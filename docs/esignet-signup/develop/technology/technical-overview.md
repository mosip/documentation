# Technical Overview

The eSignet Sign-Up Service is architected using a robust and modern technology stack that supports scalability, security, and ease of integration. It is designed to deliver a smooth user experience while ensuring reliable performance and secure data handling across all components

| Component    | Technology Stack                                          |
| ------------ | --------------------------------------------------------- |
| Frontend     | React JS (multilingual, responsive UI)                    |
| Backend      | Java, Spring Framework, Project Lombok                    |
| Data Storage | PostgreSQL, Redis (caching)                               |
| Integration  | REST APIs (OpenAPI Spec), Kafka (asynchronous operations) |
| Security     | Inbuilt Key Manager for encryption                        |

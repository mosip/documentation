# Version 0.15.1

**Release Name**: Inji Verify v0.15.1

**Support**: Patch Release

**Release Date**: 4th Nov, 2025

### Overview

The Inji Verify 0.15.1 patch release includes version updates to ensure smooth deployment and prevent issues likely to be encountered in version 0.15.0.

### Key Updates:

* In release version 0.15.0, the POM dependency of vc-verifier was 1.5.0-SNAPSHOT.
* **Fix made:** In version 0.15.1, the POM dependency version is 1.5.0
* In release version 0.15.0, the Inji Verify SDK version was 0.15.0-beta.23 which was also true for Inji Verify UI.
* **Fix made:** Inji Verify SDK is now published as 0.15.0 and Verify UI consumes the same.

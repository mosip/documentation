# End User Guide

Use this guide to verify a Verifiable Credential (VC) in the Inji Verify portal. Choose camera scan, file upload, or OpenID4VP presentation (VP) verification.

This guide is organized by verification method first, then result interpretation and common fixes:

* [Verify by scanning the QR code](./#verify-by-scanning-the-qr-code)\
  Use your device camera to scan a verifiable QR.
* [Verify by uploading the QR code](./#verify-by-uploading-the-qr-code)\
  Upload an image or PDF that contains a QR code.
* [VP verification (cross-device)](./#vp-verification-cross-device)\
  Generate a QR on one device. A wallet scans and submits a `vp_token`.
* [VP verification (same-device)](./#vp-verification-same-device)\
  Deep link to a wallet on the same device for consent and sharing.
* [Understand the verification result](./#understand-the-verification-result)\
  Read the status and interpret common failure reasons.
* [Troubleshooting](./#troubleshooting)\
  Fix camera, QR format, and expiry issues fast.

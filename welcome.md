# Welcome

### What is eSignet?

eSignet enables applications to authenticate users using trusted identity systems through standards such as OpenID Connect, without locking applications to a particular identity provider. It is an open-source digital identity authentication platform developed by MOSIP.

* **Standards-based**: Built on OpenID Connect (OIDC), functioning as both an authorization and resource server.
* **Identity-system agnostic**: Integrates with any identity system or repository that supports attribute retrieval, not just MOSIP ecosystems.
* **Open source**: Publicly inspectable code, compliance standards, and integration paths.
* **Deployable independently**: Operates as a standalone, modular identity layer for citizen portals, financial applications, and other digital services.
